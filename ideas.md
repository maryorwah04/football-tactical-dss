## Chosen approach: Touchline Ledger

### Design Movement
Contemporary editorial sports design, borrowing from coaching notebooks, field manuals, and restrained Swiss information design.

### Core Principles
1. Make every screen feel like a working coaching document, not a generic admin panel.
2. Use asymmetrical composition, clear section labels, and strong hierarchy instead of decorative complexity.
3. Keep interaction direct and calm: obvious actions, compact forms, minimal motion.
4. Treat the recommendation as a reasoned briefing that supports the coach rather than pretending to replace judgment.

### Color Philosophy
Deep pitch green provides trust and football context; warm ivory keeps the interface readable and paper-like; muted signal orange marks actions and decisions. The palette is deliberately low-saturation so the system feels useful during long planning sessions.

### Layout Paradigm
Persistent left rail for orientation, with an offset content canvas and a split dashboard: a briefing column for the coach and a tactical board column for the current state. Forms use editorial sections rather than dense tables.

### Signature Elements
1. Thin rule lines and small uppercase section labels inspired by printed coaching sheets.
2. Orange tactical markers and numbered steps for decisions.
3. A subtle pitch-grid texture used only in focal surfaces.

### Interaction Philosophy
Actions should feel like writing into a coaching notebook: add, review, edit, and submit without hidden flows. Destructive actions require explicit confirmation, while success states are concise and informative.

### Animation
Use short 160–220ms opacity and transform transitions for cards and nav states. No looping motion. Respect reduced-motion preferences. New recommendations may use a single soft slide-up reveal.

### Typography System
Use Fraunces for display headings and DM Sans for body copy, labels, and controls. Headings are compact and editorial; body copy is 14–16px with generous line height. Labels use uppercase tracking and muted green-gray.

### Brand Essence
A practical tactical planning desk for coaches and students who want repeatable, transparent match preparation without opaque automation. Personality: considered, grounded, precise.

### Brand Voice
Headlines are direct and observant. CTAs describe the action, not a vague promise. Microcopy is calm and honest about the system's limits.

Example lines:
- "Turn the scouting notes into a plan."
- "A recommendation is a starting point for the coach's decision."

### Wordmark & Logo
Use a geometric pitch-diamond mark with one offset orange marker, paired with a compact wordmark set in Fraunces rather than a default system font.

### Signature Brand Color
Signal Orange — #D86C3D. It is used sparingly for primary actions, tactical markers, and recommendation status.
